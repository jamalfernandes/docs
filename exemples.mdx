<Warning>
  **Emplacements réservés.** Les cadres de cette page attendent les vrais visuels et les vraies captures. Chaque cadre indique le format attendu et le message qu'il doit porter : il suffit de remplacer le cadre par l'image, sans toucher au reste de la page.
</Warning>

Un agent qui voit le résultat publie plus vite qu'un agent qui lit un brief. Cette page montre à quoi ressemble un post CYRUSS une fois en ligne, canal par canal.

<Info>
  Rien ici n'est à copier tel quel. Les textes sont sur la page [Textes prêts à coller](/textes), les spécifications sur la page [Visuels](/visuels). Cette page sert de repère visuel, pas de source.
</Info>

## Envoyer tes captures

<Steps>
  <Step title="Publie, puis capture" icon="camera">
    Capture le post tel qu'il apparaît dans le fil, avec ton nom visible. Pas de capture de brouillon : on veut le rendu réel, pas l'aperçu de l'éditeur.
  </Step>
  <Step title="Nomme le fichier" icon="tag">
    Format `canal-angle-nom.png`, par exemple `linkedin-proprio-b-dupont.png`. Ça évite de deviner à la réception.
  </Step>
  <Step title="Envoie-la à Boost33" icon="upload">
    Elle remplace le cadre correspondant et devient l'exemple de référence pour les autres agents.
  </Step>
</Steps>

<Danger>
  **Floute les tiers.** Si un commentaire, un message privé ou le nom d'un propriétaire apparaît sur ta capture, masque-le avant de l'envoyer. On publie ton post, pas les données de tes clients.
</Danger>
